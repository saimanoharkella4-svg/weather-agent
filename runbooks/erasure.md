# Data Erasure Runbook

## Overview
This runbook guides operators on processing user deletion requests under GDPR and India DPDP 2023.

## Right to Erasure
1. Any user can exercise their **right to** request complete **erasure** of their interaction history.
2. An **erasure** request triggers a cascade deletion across active sessions and cache partitions.
3. Confirmation of the **erasure** procedure is delivered to the requester within 72 hours.
