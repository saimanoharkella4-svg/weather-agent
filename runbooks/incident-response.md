# Incident Response Runbook

## Overview
Procedures for managing security and availability incidents impacting the Weather Agent.

## Incident Workflow
1. When a security anomaly or adversarial probe is flagged, the security on-call is alerted immediately.
2. In the event of a critical **incident**, immediate triage takes place within 15 minutes.
3. Users and stakeholders are notified via status channels if an operational **incident** impacts SLA.
